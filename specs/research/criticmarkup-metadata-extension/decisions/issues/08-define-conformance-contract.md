# Define the CM2 conformance contract and corpus

## Question

What must a conforming reader, preserving editor, and authoring editor each do,
and which normative examples and malformed-input fixtures prove those claims
across CM1 compatibility, Markdown rendering, JSON preservation, lifecycle
operations, and recovery?

Define exactly which claims the MarkText implementation and shared fixtures can
support, and avoid claiming ecosystem interoperability that would require an
independent implementation after submission.
