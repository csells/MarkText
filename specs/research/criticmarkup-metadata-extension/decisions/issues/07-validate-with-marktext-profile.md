# Implement and validate the extension on a MarkText branch

## Question

Implement the selected grammar and record model in a dedicated, opt-in MarkText
language profile and proposal branch. The branch must preserve exact source and
CM1 behavior while handling authoring, editing, copying, resolution, malformed
source, duplicate/missing records, nested syntax, undo/redo, save/reopen, and
large documents robustly.

The implementation should be complete enough to serve as credible reference
evidence for the proposal and its conformance corpus. It does not require
production rollout, polished UI, or modification of Profile 1.
